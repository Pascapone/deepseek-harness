# 基于面板的弹出窗口集成

[English](guide.md) | 中文

## 变更

分支移除 `sidebarRight.registerWindowOpener`、`popout` 和 `setPinned`。浏览器窗口的所有权、位置、暂存及重新打开由使用这些接口的插件管理。浮动面板可以容纳多个标签页；外部渲染目标由会话与面板标识，不再绑定第一个标签页。

现有的单标签页侧边栏布局仍可读取。包含多标签页浮动面板的新布局需要此运行时；旧版单标签页验证器会拒绝这些布局。会话日志及其已提交的版本不变。

## 迁移

1. 同时更新分支与弹出窗口插件。Better Web 的面板窗口实现需要 `panes`、`attachPaneTarget`、`retainSession`、`floatIn`、`closePaneIn` 和 `registerFloatHandler`。如需保留返回旧运行时的能力，升级前备份浏览器本地的侧边栏布局数据。
2. 通过公开的有序 `panes` 快照确定标签页所在的组。调用 `attachPaneTarget` 连接浏览器拥有的元素前，先获取会话保留租约。关闭浏览器窗口并释放会话租约前，先释放渲染目标并等待 DOM 返回确认。通过 `registerFloatHandler` 注册浏览器打开操作；Window 对象和会话切换策略留在插件中。
3. 将标签页固定调用替换为随插件效果释放的 `retainSession` 租约。使用原生组操作和 `canCloseIn` 处理清理与可用性，不直接修改布局存储。文件打开插件可以注册带来源标识的资源放置解析器；调用者显式指定的位置优先。
4. 验证一个弹出窗口中的两个标签页、关闭最初的标签页、整组重新停靠、会话切换及插件卸载。确认清理失败时保留原生组，禁用弹出窗口插件后原生浮动面板仍可使用。
